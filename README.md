# AI Typed Report Generator — Windows Downloads

This repository contains release downloads for AI Typed Report Generator.

Download the Windows x64 installer from [Releases](https://github.com/vadiraj-22/ai-typed-report-releases/releases). Install version 1.0.1 or later once to enable automatic update downloads. Choose **Restart to update** when an update is ready.

Saved history and API keys are retained during updates. Save or export current work before restarting. Portable copies require manual updates.
